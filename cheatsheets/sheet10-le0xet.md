**Source:** https://x.com/le0xet/status/2109965089038119023 (quotes S12 slash1sol)
**Media:** video (preview `sheet10-le0xet-preview.jpg`)

## Note text (full, via note_tweet)
- Claims Grok Bot is in a new X Subscription: "$30/month with Grok, Cursor and X Premium on one bill". **Unverified; check official X/Grok pricing pages.**
- Problem: "96 wakeups a night" and no human awake to approve. "A background approval lives about 10 minutes", then it expires.
- Fix: three **stoplines**:
  - **SCOUT** reads what changed and decides whether anyone else needs to wake.
  - **EXEC** does safe, reversible work alone.
  - **RISK** turns anything irreversible into a **draft only**.
- Claim: wasted wakeups draw on the same weekly allowance as Cursor runs. **Unverified.**

## Takeaways
The stopline split matches Grok Bot's actual rules (reversible work is fine; sends, posts, orders and deletes need explicit approval). Use it for overnight REA runs: static analysis and Evidence export can run unattended. Runtime capture against third-party systems, ADB installs, and any send/post/trade become drafts or queued approvals.
